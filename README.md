# EduPath AI (GitHub Pages Demo)

Bilingual demo (Chinese + English) for the AI admission planning system.

## Features
- Bilingual UI toggle (中文 / EN)
- Student diagnosis form
- Counterfactual analysis
- Reach / Target / Safety recommendation cards
- Human review action
- Admin panel (password: `admin2026`)
- GDPR consent checkbox
- EU AI Act compliance banner

## Deploy
This folder is ready for GitHub Pages:
1. Create a GitHub repo (e.g. `edupath-demo`).
2. Push this folder to `main`.
3. In GitHub -> Settings -> Pages, set Source to `main` / `/ (root)`.
4. Open the published URL.

## Local preview
You can double-click `index.html` to open it locally in a browser.
